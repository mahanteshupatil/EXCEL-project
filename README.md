# Swiggy Sales Analysis Dashboard - Excel

 Analyzed 197K+ Swiggy orders to find Bengaluru drives ₹5.46M sales & Non-Veg is 63% of revenue

## 📊 Project Overview
An interactive dashboard analyzing Swiggy's food delivery sales data across India. This project identifies key business trends like top-performing cities, food preferences, and monthly sales patterns to help drive data-driven decisions.

## 🔑 Key Insights
| **Metric** | **Value** | **Insight** |
| --- | --- | --- |
| **Total Sales** | ₹53.01M | Strong overall revenue |
| **Average Rating** | 4.34 / 5 | High customer satisfaction |
| **Avg Order Value** | ₹268.51 | Target for upselling |
| **Top City** | Bengaluru - ₹5.46M | Highest revenue market |
| **Food Preference** | Non-Veg 63% vs Veg 37% | Non-Veg drives majority sales |
| **Peak Sales Day** | Saturday - ₹7.78M | Weekend promotion opportunity |

## 🛠️ Tools & Technologies
- **MS Excel**: Data Cleaning, Pivot Tables, Slicers, Charts
- **Functions Used**: `IF`, `SEARCH`, `ISNUMBER`, `OR`,`TEXT`,`ROUNDUP`
- **Visualizations**: KPI Cards, Line Charts, Donut Charts, Maps, Bar Charts
- **Features**: Interactive slicers for Month, Restaurant, Category

## 📂 Dataset
- **Source**: Sample Swiggy Dataset
- **Size**: 197K+ orders
- **Key Columns**: `Order_Date`, `City`, `State`, `Food_Type`, `Sales`, `Rating`, `Restaurant_Name`

## 📈 Key Business Recommendations
1. **Focus on Bengaluru**: Highest sales at ₹5.46M. Increase delivery partner network here.
2. **Weekend Campaigns**: Saturday has peak sales of ₹7.78M. Run weekend-only discounts.
3. **Non-Veg Push**: 63% sales from Non-Veg. Create Non-Veg combo offers to increase AOV.
4. **Q3 Drop**: Q3 sales ₹13.44M vs Q1 ₹19.67M. Investigate seasonality and run Q3 promotions.

## 🚀 How to Use
1. Download `Swiggy Raw Data Excel.xlsx`
2. Open in MS Excel 2016+ or Office 365
3. Use slicers on left to filter by Month, Restaurant, Category
4. Dashboard updates automatically
